### Task 3: Surface AlwaysOn auto-approve errors in UI status

**Files:**
- Modify: `alwaysOn/libresync-always-on/src-tauri/src/main.rs`

**Step 1: Add helper to record status errors**
Add helper near `spawn_status_listener`:
```rust
fn set_status_error(status: &Arc<Mutex<AlwaysOnStatus>>, message: String) {
    if let Ok(mut status) = status.lock() {
        status.last_error = Some(message);
    }
}
```

**Step 2: Clear last_error on successful sync**
In `spawn_status_listener`, when `SyncResult::Success` is received, also clear the last error:
```rust
libresync::SyncResult::Success => {
    status.last_sync_unix_secs = Some(now_unix_secs());
    status.last_error = None;
}
```

**Step 3: Update manual refresh to clear errors on success**
In `manual_refresh_internal`, after `succeeded > 0`, add:
```rust
status.last_error = None;
```

**Step 4: Wire auto-approve errors into status**
Update `spawn_auto_approve_loop` signature to accept `status: Arc<Mutex<AlwaysOnStatus>>` and call `set_status_error` on discovery/link errors. Example updates:
```rust
Err(error) => {
    set_status_error(&status, format!("Auto-approve discovery error: {error}"));
    last_run = Instant::now();
    continue;
}
```
and
```rust
Err(error) => {
    attempts.insert(device_id, now);
    set_status_error(&status, format!("Auto-approve link failed: {error}"));
}
```
Also, after successful auto-approve, clear `last_error`:
```rust
status.last_error = None;
```
