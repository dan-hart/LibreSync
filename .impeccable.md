## Design Context

LibreSync provides local-only Nearby Sync to ordinary users of native open source apps, including As Needed and Momentum. Users need to recognize friendly device names, explicitly pair trusted devices, and understand whether their data is synced. LocalSend is the creator-provided inspiration for approachable discovery and pairing.

The requested direction is more native, attractive, calm, and clear. Use platform typography and controls, accessible semantic colors, generous but purposeful spacing, and clear status hierarchy. Apple views should feel like system settings on iOS and a native utility on macOS. Android should use Material 3. SDK views inherit the host tint; demo apps may use Electric Tangerine (#FF4F00). Avoid decorative gradients, custom control chrome, repeated titles, and ambiguous trust actions.

Preserve local-only behavior, pairing consent, credential expiry, shared-data review, and explicit Stored versus Applied receipts. Support light/dark appearance, large text, narrow windows, and long friendly names.
